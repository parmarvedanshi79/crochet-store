# Crochet Store

## Project Overview
A full-stack e-commerce website
for my handmade crochet business.

## Objective
- Learn full-stack development.
- Build an actual business website.
- Showcase my crochet products.
- Manage customer custom orders.

## Technology Stack
- Frontend: React.js
- Styling: Tailwind CSS
- Backend: Python FastAPI
- Database: PostgreSQL
- Version Control: Git and GitHub

## Version 1 Features
- Home page
- Product catalogue
- Product details
- Custom order form
- Admin dashboard
- Order management
